## 原型中的其他设计

- 保留一组变更标记区域。增强建议以空心表示未暂存、实心表示已暂存，并在连续同状态区段首行显示“未／已／已+未”。混合状态在同一实心标记上增加斜纹，并明确标注“已暂存，另有修改”，不另加轨道。绿色仍表示新增；本轮只演示新增行，不把绿色重新定义为暂存状态。
- 提供同数据的“原生示意”对照，保留原生“实心＝未暂存、空心＝已暂存”的含义，切换时同步图例。其细线轮廓仅为示意，不是原生组件截图，也不保证完全复现 GoLand 的重叠绘制。
- 悬停标记明确说明行状态；选中后显示选区内两类变化的数量。重叠行会同时计入两类，计数不是 Git hunk 数。
- 编辑器顶部操作区承接选区，不盖住代码；正常 Stage／Unstage 后保留选区及滚动位置。无选区不显示写入动作。
- 对可确认对应关系的暂存内容直接 Unstage。演示中的重叠场景被设为无法唯一对应，必须进入 HEAD ↔ INDEX，重新选择实际暂存内容；取消或返回不写入，确认只取消新选内容的暂存，本地代码保留。真实算法应根据映射证据判断，不能仅按“重叠”一概禁用。

## 体验路径

1. 不选中时比较未暂存、已暂存和重叠状态，切换原生示意查看区别。
2. 点“未暂存 111–115”，执行 Stage，检查只改变选中行的状态；再执行 Unstage。
3. 点“重叠 140–142”，进入 Diff，先返回确认没有写入，再进入选择一行执行 Unstage。
4. 选已暂存行，点演示区“模拟选区暂存后再修改”，观察原暂存内容保留及重叠状态。

可以拖动行或 Shift 点击连续选择；示例不支持真实文本编辑、删除行、未保存文档、外部 Git 并发等生产边界。
